怎么读这张图
· 实线箭头 = 基座向大模块提供契约与宿主 API（是大模块依赖基座，不是基座依赖大模块）—— 基座只认契约，不认识任何具体模块。
· 基座实际是三层：契约层 packages/core → 前端宿主 web/src/plugin → 服务端宿主 server/src/plugin（基于 @deepseek-ai/cordis 4.0.1）。
· 大模块一律平级：前端 UI 与后端服务是两个并列宿主，都消费基座，二者之间没有从属关系。
· 模式是三值：manual / auto / shared；共享库大模块被手写与 AI 写作同时复用。
