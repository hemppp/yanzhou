# UI 间距规范化 · 结项报告（2026-10-25）

> 目标：把散落的间距收成一套**有档位的尺子**，消灭野值，统一「同一容器内同档」。
> 不是重设计、不是换皮；尺寸 / 字号 / 颜色 / 布局结构一律未动。

---

## 一、为什么是 2px 尺子（不是 4px / 8px 网格）

先量了全仓 **~2230 处**间距声明，再定尺子 —— 顺序不能反：

| 值 | 用量 | 来源 |
|---|---|---|
| 8px | 492 | `gap-2` / `p-2` |
| **6px** | **405** | `gap-1.5`(167) / `py-1.5`(92) |
| 4px | 354 | `gap-1` / `p-1` |
| 12px | 344 | `p-3` |
| 16px | 160 | `p-4` |
| 2px | 156 | `py-0.5` |
| **10px** | **122** | `px-2.5`(61) |

6px 与 10px 是**事实主力档**，不是随手写的野值。硬并到 4px 网格要改 ~700 处，
且会让标签栏(30px 高) / 状态栏(10.5px 字) 这些**刻意密排**处整体变松。

**结论**：尺子 = **2px 步进**，12px 以下 2px 一步、12px 以上 4px 一步。
真野值（1/3/5/7/9/11/13/14/18/22/26/42）才是要清的东西。

## 二、令牌（`apps/web/src/styles/globals.css`）

```css
--space-0: 2px;   /* 光学微调：图标↔文字、徽章对齐。不承载结构间距 */
--space-1: 4px;   /* 紧邻：同一控件内 */
--space-2: 6px;   /* 密排：标签栏 / 状态栏 / 气泡列 / 工具栏内部 */
--space-3: 8px;   /* 常规：控件内边距（最常用） */
--space-4: 10px;  /* 松档：密排区的内边距 */
--space-5: 12px;  /* 区块内 */
--space-6: 16px;  /* 卡片 / 面板内边距 */
--space-7: 20px;  /* 大卡片内的分区 */
--space-8: 24px;  /* 区块与区块之间 */
--space-9: 32px;  /* 页面级大留白 */
--space-10: 48px; /* 页面级空态 / 加载态的纵向呼吸（唯一的大留白档） */
```

Tailwind 数字档 → 令牌是**一一对应**的（`p-2`=space-3 等），所以 `tsx` 里继续用
`p-2` / `gap-3` / `px-2.5`，**不另造** `p-space-2` 这种第二套方言。
`.css` 与内联样式一律用 `var(--space-N)`。

规范已写入 `docs/design/design-system.md § 间距系统`。

## 三、结果（可复算）

探针脚本：`D:\Temp\spacing-audit\spacing-audit.mjs`（统计 Tailwind 非法档位 / 内联非档位值 / CSS 非法 px）

| 维度 | 改前 | 改后 |
|---|---:|---:|
| Tailwind 非法档位 | 34 | **0** |
| 内联样式非档位值 | 51 | **3** |
| CSS 文件非法 px | 24 | **2** |
| **合计** | **109** | **5** |

> 注：不同轮次脚本口径微调（排除 landing 页面节奏豁免、排除负值布局手法），
> `BEFORE` 用同一版脚本重跑为 **102**，`AFTER` 为 **5**。

剩下 5 处全部**有意保留**：

- `EditorPage.tsx` 3 处 `clamp(24px,4vh,40px)` 类**响应式流式内边距** —— 端点值改死会让不同视口正文宽度跳变；
- `globals.css` 打字机光标 `1px`、横格纸基线 `1.5px` —— 发丝级光学值，不是结构间距。

令牌实际采纳：**534 处** `var(--space-N)` 引用（编译产物中 61 处，其余在 tsx 内联样式里由运行时求值）。
CSS 侧结构间距已 **100% 走令牌**，只剩 4 处负值/发丝值。

## 五、顺带做的「可发现性」（走查报告 C 批）

### U5 · 气泡列操作提示 ✅
原来只有原生 `title`（悬停 ~1s，触屏/键盘下不存在），而单击=预览、双击=固定这条语义
**没有任何界面提示**。

改法：portal 到 body 的自绘浮层（`fixed`），150ms 出现，显示「面板名 + 分组 + 单击预览 · 双击固定」。
**必须用 portal**：气泡列自身是 `overflow-y: auto`，一个轴设 auto 会把另一轴的 visible 强制成 auto，
绝对定位浮层会被整列裁掉（2026-09-13 就是因为这个放弃了自绘）。原生 `title` 保留。

实测踩到的坑（已修）：浮层按「气泡垂直居中」定位时会**压住标签栏**——
第一颗气泡中心只比标签栏底边高一点点。改为运行时量气泡列自身顶边 + 标签栏 30px + 半高夹取。
复验：`clearsTabbar: true`（浮层 top 87 > 标签栏底 78）。

### U8 · 空态主按钮 ✅
对话区与正文区两处空态各加一个「写第 1 章」主按钮（已有章但该章为空时，按钮写的是**那一章**的章号）。
点击后把预设指令**填进输入框并聚焦**，**不自动发送** —— 每章都要真实跑完整编排、花额度，最后一下必须由作者按。
若输入框已有草稿则不覆盖。

复验：`value = "写第 1 章："`、`focused = true`、`userTurns = 0`（确认没误发）。

## 七、留档：这次没做，但值得下一轮

1. `px-4 py-2 + gap-1.5` 这种「横向 16 / 纵向 8」的按钮形状语法在全仓有几百处，
   严格按「同一容器同档」都算跨档。批量改会整体改变控件手感，需先定按钮规格。
2. 停用件（`PipelinePanel` / `EntityRail` / `MemoryAuditPanel`）已顺手收敛，但它们本身是**死代码**，
   下一轮清理时可一并删除。
3. CI 没有 CSS 编译、没有像素回归。若要长期守住这套尺子，建议加一条
   `spacing-audit.mjs` 式的静态门禁（把「野值数」作为阈值断言）。
